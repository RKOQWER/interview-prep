# M2 - OOP that gets scored (2 sessions)

Scope: the OOP vocabulary interviewers score, each as violation -> fix -> drill.

## Session 1 - Encapsulation as invariants, abstraction, inheritance vs composition

**Encapsulation = invariants, not boilerplate.** A class is a bodyguard: it exists to protect what must always be true. Getter/setter pairs with no rules are noise - that's public fields wearing a costume.

```ts
// VIOLATION: nothing enforces "status can't skip 'done' checks"
class Task { title = ""; status: Status = "todo"; }

// FIX: the only mutation path goes through a guard
class Task {
  #status: Status = "todo";
  get status(): Status { return this.#status; }
  setStatus(s: Status): void {
    if (s === "done" && this.#status === "todo") throw new Error("cannot skip in_progress");
    this.#status = s;
  }
}
```

Rule: every mutable field goes through a method that validates. If no validation exists, the field can be public.

**Abstraction:** callers depend on the promise (interface), not the mechanism. Already used at `Repository<T>` (M1.5).

**Inheritance vs composition - the is-a / has-a test:**

```ts
// is-a: "An ElectricCar IS-A Vehicle" - hard to change later
class ElectricCar extends Vehicle { ... }

// has-a: "A Car HAS-A Battery" - swap Battery freely
class Car { constructor(private battery: Battery) {} }
```

Default to composition. Inheritance only for a genuine IS-A with shared behavior you'd reuse verbatim. The classic trap: `Square extends Rectangle` - works geometrically, breaks `setWidth` invariants (Liskov violation).

**Drill:** refactor a procedural script (a bag of functions + a global state object) into 2-3 classes with protected invariants; then swap an `extends` hierarchy for composition.

**Build:** give `TaskStore` a guarded mutation path - no direct writes to task status outside `setStatus`.

**Definition of done:** vitest green, `tsc --noEmit` clean, and you can state in one line: "encapsulation means the class can defend its invariants."

**Wrap:** commit `M2.1: invariants + composition over inheritance`.
